# Examples

Ready-to-use recipes for common workflows.

- **[prompts/](prompts/)** — system prompts and one-off prompts for Claude Desktop / Claude Code triage sessions
- **[cron/](cron/)** — shell scripts for scheduled digests and automation via cron
- **[claude-code-commands/](claude-code-commands/)** — a Claude Code slash command for daily inbox triage

Each file is self-contained — copy what you need, adjust folder names/addresses, and go.
